# 📔 戀人手帳 Lover's Planner

給 [TauriTavern](https://github.com/Darkatse/TauriTavern) / SillyTavern 用的長期記憶擴充。
聊了幾千層之後，角色還記得你們去過哪裡、約好了什麼、哪天是紀念日，而且送出去的 token 不會越滾越大。

- **摘要**：每一層 AI 回覆寫一小段摘要，舊的原文不再整段送出，只送摘要。
- **壓縮**：摘要再往上壓成章、卷、部…（沒有層數上限），越舊越精簡。
- **記事**：人物、物件、約定、待辦，自動記下、自動更新，完成的收進「已完成」。
- **行事曆**：故事裡的日期、行程、紀念日、生理期、親密的日子。
- **回憶錄**：值得珍藏的時刻，偶爾讓角色自然地想起「還記得那天…」。
- **補建**：聊了很久才開始用？一鍵把舊樓層的摘要和記事補起來。

介面有繁體中文、简体中文、English。

## 安裝和更新

**安裝**：TauriTavern／SillyTavern → 擴充功能 → 安裝擴充 → 貼上：

```
https://github.com/tammynbq/ST-LoversPlanner
```

**更新**：在擴充功能管理裡按更新。預設會在更新後**自動重新整理**（等摘要、生成都做完、大視窗關著時才會重新整理，輸入框裡打到一半的字會保留）。不想要可以到「設定 › 一般」關掉。

目前的版本號寫在大視窗標題旁邊，和「設定 › 一般」最下面。

## 第一次使用：建議的設定步驟

打開方式：點輸入框旁的 **魔術棒** → **戀人手帳**，會打開大視窗。也可以在擴充設定面板裡按「打開戀人手帳」。

1. **模型來源**（設定 › 模型來源）
   摘要要呼叫模型。建議用**自訂 API**，接一個便宜、不會「先思考」的模型，例如 DeepSeek 的 `deepseek-chat`。用酒館的主 API 也可以，但主模型通常比較貴。
   填好網址、金鑰，按「拉取模型」選模型，再按「測試」確認能用。
2. **摘要時跳過的內容**（設定 › 摘要時跳過的內容）
   在「AI 樓層用到的標籤」選掃描範圍（最新 2 層、最新 30 層或全部），看你的回覆裡有哪些標籤（狀態欄、思維鏈、生圖提示、排版…），把用不到的設成「不讀」。
   狀態欄裡如果有日期、時間、地點，可以設成「**只當參考**」：不當正文，但讓模型知道故事日期。
   這一步做好，能省下非常多 token。
3. **記錄項目**（設定 › 記錄項目）
   勾選要記哪些：時間、地點、出場人物、人物、物件、約定、待辦，以及人物要記哪些欄位。
4. **行事曆**（設定 › 行事曆）
   想記故事日期就開著。如果故事一開始沒寫日期，可以填「故事開始日」。
5. **摘要模式**（設定 › 摘要）
   - 每回正文結束後自動摘要（最省心）
   - 開始下回前自動摘要（你送出下一句時才摘上一層，重新生成時不會白摘，比較省）
   - 手動
6. **已經聊很久了？** 到「摘要」分頁按「**補建舊樓層**」，見下面的[補建](#補建舊樓層)。

## 功能說明

### 摘要

- **重做**：不滿意就重做，舊的那一版會存起來（最多 5 個），在「其他版本」裡比較，按「用這一版」換回來。可以拿來比較不同模型。
- **👻 跳過**：不重要的樓層（OOC、閒聊）可以跳過：不摘要、不呼叫模型，原文也不再送。
- **⭐ 小劇場**：番外、小劇場、IF 線用這個：不寫進正劇摘要、原文也不再送，但會讀一次，把值得珍藏的回憶、之後正劇也算數的約定和待辦記下（只會新增，不會改動人物、物件）。小劇場的回憶在回憶錄裡會標「小劇場」。
- **多選**（摘要分頁 › 多選）：一次摘要、重新摘要、👻 跳過、⭐ 小劇場（和取消），或把連續的樓層壓成一章。
- **送出預覽**（摘要分頁最上面）：看這次會送給角色什麼、各部分大約多少 token。

### 壓縮：章、卷、部…

已經摘要好的舊樓層，每 10 層壓成一**章**，每 5 章壓成一**卷**，再往上每 5 個壓成**部**、**紀**…（數量可以在「設定 › 壓縮」調）。送給角色時只送最上層還有效的那一份，越舊越精簡。

- 壓縮時模型會順便歸納 1～2 個主要地點，時間會補上日期。
- 下面的摘要改過，上面的章、卷會變成「**過期**」，送的時候自動改用下一層。
- 重新壓縮一直失敗的話，可以按「**保留現在的總結**」（不呼叫模型，拿掉過期標記），或在篩選「過期」「失敗」時「全部保留」。

### 隱藏和注入

戀人手帳送出時會把**已經摘要好的舊樓層原文拿掉**，換成摘要和記事；最新 2 層一定保留原文。

- 注入位置（設定 › 注入）：預設放在最新原文前面。
- **也用酒館的「隱藏」標起來**（設定 › 隱藏，預設關）：再用酒館自己的隱藏把這些樓層標起來，酒館算的 token、其他擴充看到的聊天也不含它們。摘要過期時會自動取消隱藏。只動戀人手帳自己標的，你自己 `/hide` 的不會被碰。
- 你自己隱藏的樓層，照樣算樓層、摘要照樣送。

### 記事

**人物**：名字、別稱、身份／職業、年齡、生日、和 user 的關係、和 char 的關係、外貌特徵、當前衣著、當前狀態、性格、喜歡、不喜歡、習慣／口頭禪、重要經歷、備註（不要的欄位可以在「記錄項目」關掉）。
- 人物卡上可以按「**設為 user／設為 char**」指定主角；沒指定時用名字自動認。
- 重複的人物可以用 🩺 檢查合併，被合併那條後來的更新會自動併過去。

**物件**：只記兩人的所有物，數量、在誰手上。

**約定／待辦**：
- 短標題（15 字內）、完整內容、和誰、原文說的時間、**預定日期**（明天、下週三…會換算成實際日期）。
- 卡片上會標「📅 10-28 週三・4 天後」，過期的是紅色。
- 可以依預定日期或約定日期排序，篩選「N 天內到期／已過期／沒有日期」。
- 舊的約定沒有短標題的話，上方有「補標題」按鈕。
- 完成後收進「已完成」，會寫完成於哪天、已過幾天、**怎麼完成的**。

**只送相關的**（設定 › 只送相關的＋回憶召回）：記事很多時，只送和現在聊的內容有關的（主角和釘選的一定送）。可以另外接向量模型（例如硅基流動的 `BAAI/bge-m3`）讓比對更準。

### 行事曆

模型摘要時會推算每一層是故事裡的哪一天，並記下：
- 📌 行程、🎂 紀念日／生日、💕 親密的日子（次數）、🩸 {{user}} 的生理期
- 約定／待辦的預定日期也會標在月曆上（🤝／📝）

**生理期**：只記劇情明確提到的開始和結束，不需要填週期。
- 可以開「**推算下次生理期**」（預設關）：用最近 6 次週期的最短～最長，給一個範圍，不給單一日期；也可以推算排卵期。
- 開了推算，快到、晚了、很久沒來、可能在排卵期時，會用不確定的語氣告訴角色。只是故事用的估計，不是醫療依據。

只把「今天」和「接下來幾天」的事送給角色，不會把整本行事曆塞進去。

### 回憶錄

- 摘要時模型會挑真正值得珍藏的時刻（寧缺勿濫），你也可以在摘要區塊按「💝 收藏成回憶」。
- 小劇場、番外預設不寫進正劇摘要，但有意義的可以收進回憶錄。
- **想起過去**：大約每 10 回，隨機挑 1～2 條夠舊、最近沒提過的回憶，讓角色「可以自然地提起，不勉強」。
- 回憶錄不會被壓縮。

### 帶走／共用（設定 › 記憶範圍）

同一個角色開新聊天時，可以選擇把人物、約定、摘要等「複製帶走」或「即時共用」，也可以從別的聊天匯入。新聊天可以有一段「前情提要」（濃縮版或原樣）。

### 補建舊樓層

摘要分頁 →「補建舊樓層」：
- **範圍**、**最近幾層一層一層細摘**、**更舊的每幾層寫成一章**（粗略，但省很多次呼叫）。
- 開始前會顯示預估的呼叫次數和 token，以及「還會送出的標籤」，可以當場改成不讀。
- 開始或繼續前會先找出可能是**番外／小劇場／IF 線**的樓層，列出來讓你選 👻 跳過、⭐ 小劇場（預設）或照常摘要。
- 進度會記住，切 App 或關掉後回來可以接著做。
- **先換成便宜的自訂 API 再補建**。

粗略補建的章可以之後按「改成逐層細摘」。

### 🩺 檢查

找出：沒摘要、失敗、過期、摘要太長或太短、重複的記事、數量 0 的物件、過期的章和卷…。每一項都有修正按鈕，也可以「全部修正」。還可以請模型抽查幾層摘要寫得對不對。

### 資料管理（設定 › 資料管理）

- **導出備份**：這個聊天的戀人手帳內容存成 `.json`（可以選擇包含設定，**API 金鑰一定不會放進去**）。
- **導入備份**：合併（只補沒有的）或覆蓋。可以用來換裝置、在 SillyTavern 和 TauriTavern 之間搬、開分支聊天時帶過去。
- **重新檢查番外**：檢查所有樓層，一鍵設成 👻 跳過或 ⭐ 小劇場。
- **刪除本窗口的內容**：會先自動下載備份。聊天本身不動，和其他聊天共用的記事不清。

### 調用紀錄（設定 › 調用紀錄）

戀人手帳自己每次呼叫模型都會記下：用途、模型、送出／回覆 token、花幾秒、成功或失敗。可以看今天、近 7 天、近 30 天，以及各模型、各用途的統計，比較模型時很好用。不包含你平常聊天本身。

### 系統提示詞（設定 › 模型來源）

- 「**說明這是成人虛構故事**」（預設開）：告訴模型這是成年人、雙方同意的虛構故事，親密的段落照實、不露骨地記下，比較不會拒絕或回空。
- **自訂前言**：可以貼你自己預設裡的說明。

## 省錢小技巧

1. **摘要用便宜的自訂 API**，聊天用你喜歡的主模型。
2. **設好要跳過的標籤**：狀態欄、思維鏈、排版、生圖提示通常佔掉一大半，跳過或「只當參考」。
3. 摘要模式選「**開始下回前**」：重新生成、swipe 時不會白摘。
4. 補建時，舊的部分用「每幾層寫成一章」的粗略方式。
5. 記事很多時開「只送相關的」。
6. 看「調用紀錄」找出哪個用途、哪個模型最花。

## 常見問題

**模型一直回空的、或顯示服務商的通知（例如「响应内容为空」）**
- 可能是內容被模型的安全過濾擋掉。換一個比較寬鬆的模型或服務商，或確認「說明這是成人虛構故事」有開著。
- 戀人手帳會自動重試 2 次。只回了服務商通知的，不會被當成摘要存進去。

**等太久（逾時）**
- 自訂 API 預設等 120 秒，可以在「設定 › 模型來源」調長（最多 600 秒）。會「先思考」的模型通常比較慢。

**「模型把輸出額度都用在思考上」**
- 會思考的模型把額度花在思考上，沒寫出內容。戀人手帳會自動加倍額度再試；還是不行的話，換一個不用思考的模型。

**部、卷的重新壓縮一直失敗**
- 按「保留現在的總結」，或篩選「失敗／過期」後「全部保留」。

**摘要分頁上方的「失敗」「過期」數字對不上**
- 數字包含章、卷、部，點進去會列出來。

**大視窗打不開、只看到一行字、被主題蓋住**
- 先確認已更新到最新版（看版本號）。如果還是不行，截圖給開發者。

**更新後沒變化**
- 重新整理一次頁面。TauriTavern 有時要整個 App 重開。

**記事裡出現「（這條記事已刪除或合併）」**
- 那是指向已經被刪掉或合併的記事的舊變化，資料已經併到留下的那條，不用處理。

## 資料和隱私

- 摘要存在**每一則訊息裡**（跟著聊天檔案走），章、卷、記事、行事曆等存在**聊天的資料**裡；設定存在酒館的設定裡。
- 除了你選的模型 API（和你開的向量 API），戀人手帳不會把資料送到其他地方。
- **API 金鑰是以明文存在酒館的設定裡**，和酒館其他設定一樣。分享設定檔或截圖時請注意；導出的備份不含金鑰。
- 刪除戀人手帳的內容不會動到聊天本身。
