# 📔 戀人手帳 Lover's Planner

給 [TauriTavern](https://github.com/Darkatse/TauriTavern) / SillyTavern 用的記憶擴充：

- 替每一層 AI 回覆寫摘要（自動／手動／跳過）
- 每 10 個摘要壓成一份章節總結，再往上壓成卷總結，真正省下 token
- 記錄人物、物件、約定、待辦，完成後自動收進「已完成」

介面有繁體中文、简体中文、English 三種語言。

> 🚧 開發中。目前完成的是骨架：三語介面、魔術棒入口、大視窗和設定頁。
> 完整規格與進度見 [SPEC.md](SPEC.md)。

## 安裝

TauriTavern／SillyTavern → 擴充功能 → 安裝擴充 → 貼上：

```
https://github.com/tammynbq/ST-LoversPlanner
```

## 使用

- 點輸入框旁的 **魔術棒** → **戀人手帳**，打開大視窗。
- 或在擴充設定面板裡按 **打開戀人手帳**。
